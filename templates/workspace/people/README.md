# People

One note per person (`type: person`, template `templates/person.md`). Projects point to them with `rel_involves`. Your own note (the user) is named in `korrigans.toml` (`user`).

The agents never write to these people: at most a draft, which the user sends themselves. A note holds the role, the work and what can be asked of the person; no private detail that the projects do not need.
